 Лабораторная работа №1: Базовые классы

## 📋 Задание
Реализовать базовую версию эффекта "цифрового дождя"
Создать систему для отображения анимированных линий в консоли Windows.

## 🏗 Архитектура

### Основные классы:
2. **`Line`** (наследник Figure)
   - Управление движением "ромбической" линии
   - Отрисовка символов с градиентом цвета
   - Базовая логика жизненного цикла

3. **`AppManager`**
   - Единый цикл управления
   - Планирование создания новых линий
   - Управление коллекцией активных фигур
