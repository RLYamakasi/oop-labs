# 🌧️ Matrix Rain - Эффект цифрового дождя

## 📋 Описание проекта

Проект реализует знаменитый эффект «цифрового дождя» из фильма *The Matrix* в терминале с использованием библиотеки ncurses. Проект развивается от простой анимации к сложной системе с эффектами и собственными структурами данных, демонстрируя эволюцию программного обеспечения.

## 🎯 Особенности

- **Полноэкранная анимация** в терминале с использованием ncurses
- **Настраиваемые параметры**: скорость, длина линий, частота появления
- **Система взрывов** с радиальным расхождением символов
- **Собственные реализации контейнеров** (списки, массивы)
- **Два режима ввода**: интерактивный и CLI
- **Защита от некорректного ввода**

## 🏗 Архитектура проекта

### Основные модули:

| Модуль | Назначение | Файлы |
|--------|------------|-------|
| **app_manager** | Главный цикл приложения, управление жизненным циклом | `app_manager.h`, `app_manager.c` |
| **myLine** | Логика движения и отрисовки одной линии | `myLine.h`, `myLine.c` |
| **symbol** | Работа с отдельными символами (печать/удаление) | `symbol.h`, `symbol.c` |
| **winFunc** | Работа с ncurses: цвета, курсор, размер окна | `winFunc.h`, `winFunc.c` |
| **input_utils** | Ввод и валидация параметров пользователя | `input_utils.h`, `input_utils.c` |
| **explosion** | Эффект взрыва (начиная с lab-03) | `explosion.h`, `explosion.c` |

### Собственные структуры данных (lab-04):

| Структура | Аналог STL | Назначение |
|-----------|------------|------------|
| **MyList** | Общий интерфейс | Базовый класс для списков |
| **ArrayList** | `std::vector` | Динамический массив |
| **LinkedList** | `std::list` | Двусвязный список |

## ⚙️ Параметры запуска

### Обязательные параметры (все ветки):
1. **Скорость** (speed) — `1-30` символов в секунду
2. **Длина** (length) — `1-30` символов
3. **Режим эпилепсии** (epilepsy) — `Y/N` (безопасная цветовая палитра)

### Добавленные в lab-02:
4. **Частота появления** (spawnRate) — `1-30` линий в секунду

### Добавленные в lab-03:
5. **Вероятность взрыва** (explosionChance) — `1-1000` (1 из N шанс)
6. **Минимальный радиус** (minRadius) — `1-10` символов
7. **Максимальный радиус** (maxRadius) — `minRadius-10` символов
