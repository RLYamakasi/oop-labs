# Лабораторная работа №4: "Велосипедизация"

## 📋 Задание
Рефакторинг программы "Матрица" путем замены стандартных контейнеров STL на собственные реализации. Все контейнеры должны быть реализованы "с нуля" в стиле С++.

## 🎯 Цель работы
Углубленное понимание внутреннего устройства контейнеров, управление памятью, реализация итераторов, освоение принципов RAII и исключительной безопасности.
